## AI Things Considered

A daily comic strip generated by AI, inspired by NPR's All Things Considered.

Every day, an AI reads the latest stories from NPR's All Things Considered, selects six with visual potential, and renders them as a vintage newspaper-style comic strip.

### Free to Use

The generated comic images and associated metadata (story links, titles, summaries) are **free for anyone to use**. Embed them, share them, build on them. Each comic includes links back to the original NPR stories.

- **Images**: `comics/ai-things-considered/{date}.png`
- **Metadata**: `comics/ai-things-considered/{date}.json`

### How It Works

1. Fetch stories from NPR's All Things Considered RSS feed
2. AI selects 6 stories based on visual potential and topic diversity
3. AI generates image prompts in a vintage comic aesthetic
4. Gemini 3 Pro renders each panel
5. Panels are composited into a 3x2 grid with title and date
